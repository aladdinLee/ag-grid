# AG Grid Core Concepts

> This document covers core concepts shared across all frameworks (React, Angular, Vue, JavaScript). For framework-specific usage, see the respective llms-{framework}.txt files.

## Module Registration

AG Grid requires module registration for NPM installations. Use bundles for all features or cherry-pick modules for smaller bundles.

### Bundle Approach

```javascript
// All Community features
import { AllCommunityModule, ModuleRegistry } from 'ag-grid-community';
ModuleRegistry.registerModules([AllCommunityModule]);

// All Community + Enterprise features
import { AllEnterpriseModule } from 'ag-grid-enterprise';
ModuleRegistry.registerModules([AllEnterpriseModule]);
```

### Individual Modules

```javascript
import { ClientSideRowModelModule, CsvExportModule } from 'ag-grid-community';
import { SetFilterModule, ExcelExportModule, RowGroupingModule } from 'ag-grid-enterprise';

ModuleRegistry.registerModules([
    ClientSideRowModelModule,  // Required for default row model
    CsvExportModule,
    SetFilterModule,
    ExcelExportModule,
    RowGroupingModule
]);
```

### Validation Module (Development)

```javascript
import { ValidationModule } from 'ag-grid-community';

if (process.env.NODE_ENV !== 'production') {
    ModuleRegistry.registerModules([ValidationModule]);
}
```

### Check Module Registration

```javascript
const isRegistered = api.isModuleRegistered('SetFilterModule');
```

## Column Definitions

Columns are defined via `columnDefs` array. Each column has properties controlling sorting, filtering, editing, rendering, and more.

### Basic Column Definition

```javascript
const columnDefs = [
    { field: 'athlete' },                          // Basic - header derived from field
    { field: 'age', headerName: 'Age (years)' },   // Custom header name
    { field: 'country', sortable: true, filter: true },
    { field: 'sport', editable: true },
    { field: 'id', pinned: 'left' },
    { field: 'notes', flex: 1, minWidth: 150 },
];
```

### Default Column Definition

Apply properties to all columns:

```javascript
const gridOptions = {
    defaultColDef: {
        sortable: true,
        filter: true,
        resizable: true,
        minWidth: 100
    }
};
```

### Column Types

```javascript
const gridOptions = {
    columnTypes: {
        currency: {
            width: 150,
            valueFormatter: params => `$${params.value}`
        },
        numeric: {
            type: 'rightAligned',

        }
    },
    columnDefs: [
        { field: 'price', type: ['currency', 'numeric'] },
        { field: 'quantity', type: 'numeric' }
    ]
};
```

### Column Groups

```javascript
const columnDefs = [
    {
        headerName: 'Medals',
        children: [
            { field: 'gold' },
            { field: 'silver' },
            { field: 'bronze' }
```

### Column State

```javascript

const state = api.getColumnState();

// Apply column state

    state: [
        { colId: 'athlete', sort: 'asc', width: 200, pinned: 'left' }
    ],
    defaultState: { sort: null }

// Reset column state

```

## Row Models

### Client-Side Row Model (Default)

All data loaded into browser memory. Supports local sorting, filtering, grouping.

```javascript
const gridOptions = {
    rowModelType: 'clientSide',  // Default
    rowData: dataArray
};
```

### Server-Side Row Model (Enterprise)

Lazy loading with server-side operations. Ideal for large datasets.

```javascript
const gridOptions = {
    rowModelType: 'serverSide',
    serverSideDatasource: {
        getRows: (params) => {
            const { request } = params;
            // request contains: startRow, endRow, sortModel, filterModel, rowGroupCols, groupKeys

            fetch('/api/data', {
                method: 'POST',
                body: JSON.stringify(request)
            })
            .then(response => response.json())
            .then(data => {
                params.success({
                    rowData: data.rows,
                    rowCount: data.lastRow
                });
            })
            .catch(() => params.fail());
        }
    },
    cacheBlockSize: 50,
    maxBlocksInCache: 10
};
```

### Infinite Row Model

Lazy loading for large flat datasets. Server handles sorting/filtering.

```javascript
const gridOptions = {
    rowModelType: 'infinite',
    datasource: {
        getRows: (params) => {
            const { startRow, endRow, sortModel, filterModel } = params;

            fetchData(startRow, endRow, sortModel, filterModel)
                .then(data => params.success(data.rows, data.lastRow))
                .catch(() => params.fail());
        }
    },
    cacheBlockSize: 100
};
```

### Viewport Row Model

Server-driven updates for real-time data streams.

```javascript
const gridOptions = {
    rowModelType: 'viewport',
    viewportDatasource: {
        init: (params) => { /* Store callbacks */ },
        setViewportRange: (startRow, endRow) => { /* Fetch range */ },
        setRowCount: (count) => { /* Set total rows */ }
    }
};
```

## Data Updates

### Client-Side Updates

```javascript
// Replace all data
api.setGridOption('rowData', newData);

// Update single row/cell
const rowNode = api.getRowNode('row-id');
rowNode.setDataValue('price', newPrice);    // Single cell
rowNode.setData(newRowData);                 // Entire row
rowNode.updateData(partialData);             // Partial update (refreshes only changed cells)

// Transaction updates
const result = api.applyTransaction({
    add: [newRow1, newRow2],
    addIndex: 3,              // Insert position
    update: [updatedRow],
    remove: [{ id: 'row-id' }] // Matched by getRowId
});

// Async transactions for high-frequency updates
api.applyTransactionAsync({ add: [row] }, (result) => {
    console.log('Update complete');
});
api.flushAsyncTransactions();  // Force immediate flush
```

### Server-Side Updates

```javascript
// Refresh all data
api.refreshServerSide({ purge: true });

// Refresh specific route
api.refreshServerSide({ route: ['USA', 'Swimming'] });

// Transaction updates
api.applyServerSideTransaction({
    update: [{ data: newData }],
    remove: [{ id: 'row-id' }]
});
```

### Column Filters

```javascript
const gridOptions = {
    columnDefs: [
        { field: 'athlete', filter: true },                    // Default text filter
        { field: 'age', filter: 'agNumberColumnFilter' },
        { field: 'date', filter: 'agDateColumnFilter' },
        { field: 'country', filter: 'agSetColumnFilter' },     // Enterprise

    ]

```

### Set Filter (Enterprise)

```javascript
const gridOptions = {
    columnDefs: [
        {
            field: 'country',
            filter: 'agSetColumnFilter',
            filterParams: {
                values: ['USA', 'UK', 'Canada', 'Australia'],
                caseSensitive: false,
                excelMode: 'and',           // Excel-like behavior
                treeList: true,             // Hierarchical display
                searchDebounceDelay: 300
            }
        }
    ]
};

// Async values
filterParams: {
    values: (params) => {
        fetchValues().then(values => params.success(values));
    }
}
```

### Quick Filter

Searches across all columns:

```javascript
const gridOptions = {
    quickFilterText: 'search text',
    cacheQuickFilter: true,
    quickFilterParser: (text) => text.split(' '),   // Split into words
    quickFilterMatcher: (parts, rowQuickFilterText) => {
        return parts.every(part => rowQuickFilterText.includes(part));
    }
};

// API update
api.setGridOption('quickFilterText', 'new search');
```

### External Filter

```javascript
let externalFilterActive = false;

const gridOptions = {
    isExternalFilterPresent: () => externalFilterActive,
    doesExternalFilterPass: (params) => {
        return params.data.status === 'active';
    }
};

// Activate external filter
externalFilterActive = true;
api.onFilterChanged();
```

### Filter API

```javascript
// Get/set entire filter model
const model = api.getFilterModel();
api.setFilterModel({ country: { values: ['USA'] } });

// Individual filter
await api.setColumnFilterModel('country', { values: ['USA', 'UK'] });
api.onFilterChanged();

// Get filter instance
const filterInstance = api.getColumnFilterInstance('country');
```

## Cell Data Types

Automatic type inference for proper rendering, editing, filtering.

Built-in types: `text`, `number`, `bigint`, `boolean`, `date`, `dateString`, `dateTime`, `dateTimeString`, `object`

```javascript
const gridOptions = {
```

## Cell Styling

```javascript
const gridOptions = {
    columnDefs: [
        // Static style
        { field: 'status', cellStyle: { color: 'red', backgroundColor: '#ffe0e0' } },

        // Dynamic style (function)
        {
            field: 'value',
            cellStyle: params => {
                if (params.value > 100) return { backgroundColor: 'green' };
                if (params.value < 0) return { backgroundColor: 'red' };
                return null;
            }
        },

        // CSS classes
        { field: 'name', cellClass: 'highlight-cell' },

        // Dynamic CSS class rules
        {
            field: 'profit',
            cellClassRules: {
                'profit-positive': params => params.value > 0,
                'profit-negative': params => params.value < 0,
                'profit-zero': params => params.value === 0
            }
        }
    ]
};
```

## Value Formatters / Getters / Setters / Parsers

### Value Formatter (Display)

```javascript
const columnDefs = [
    { field: 'price', valueFormatter: params => `$${params.value.toFixed(2)}` },
    { field: 'date', valueFormatter: params => params.value.toLocaleDateString() }
];
```

### Value Getter (Retrieve)

```javascript
const columnDefs = [
    // Instead of field, use valueGetter
    { headerName: 'Full Name', valueGetter: params => `${params.data.firstName} ${params.data.lastName}` },
    { headerName: 'Total', valueGetter: params => params.data.gold + params.data.silver + params.data.bronze }
];
```

### Value Setter (Save)

```javascript
const columnDefs = [
    {
        headerName: 'Full Name',
        valueGetter: params => `${params.data.firstName} ${params.data.lastName}`,
        valueSetter: params => {
            const names = params.newValue.split(' ');
            params.data.firstName = names[0];
            params.data.lastName = names.slice(1).join(' ');
            return true;  // Return true if update successful
        }
    }
];
```

### Value Parser (Parse Input)

```javascript
const columnDefs = [
    { field: 'age', valueParser: params => Number(params.newValue) }
];
```

## Custom Components

### Cell Renderer

```javascript
// Function renderer
const columnDefs = [
    { field: 'price', cellRenderer: params => `$${params.value}` }
];

// Class renderer
class StatusRenderer {
    agInit(params) { this.params = params; }
    getGui() {
        const div = document.createElement('div');
        div.className = `status-${this.params.value}`;
        div.textContent = this.params.value;
        return div;
    }
    refresh(params) { return false; }  // Return true to refresh in-place
}

const columnDefs = [
    { field: 'status', cellRenderer: StatusRenderer }
];
```

### Dynamic Renderer Selection

```javascript
const columnDefs = [
```

## Aggregation (Enterprise)

Built-in functions: `sum`, `min`, `max`, `count`, `avg`, `first`, `last`

```javascript
const gridOptions = {
    columnDefs: [
        { field: 'gold', aggFunc: 'sum' },
        { field: 'silver', aggFunc: 'avg' },
        { field: 'count', aggFunc: 'count' }
    ],
    // Custom aggregation
    aggFuncs: {
        range: params => {
            const values = params.values;
            return Math.max(...values) - Math.min(...values);
        }
    }
};
```
